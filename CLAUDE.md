# ohmybug-plugin — agent rules

**This repo is PUBLIC.** Everything committed, filed or commented here is
visible to the world.

- **No internal tickets here.** Bugs and work items — including bugs in this
  plugin — belong in the private tracker:
  `gh issue create --repo exply-dev/OhMyBug ...`. Always pass `--repo`
  explicitly; `gh` defaults to this clone's remote and would publish internal
  work (happened 2026-08-12).
- **English only** for every public artifact: code, comments, docs, commit
  messages, issues, PRs, release notes, user-facing plugin text.
- No AI trailers / `Co-Authored-By` in commits.
